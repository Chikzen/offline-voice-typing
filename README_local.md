# Локальний рушій: Parakeet TDT 0.6B v3 на CPU

Звіт за ТЗ «Локальный потоковый голосовой ввод на Windows» v1.0 від 13.09.2026.
Виконано етапи 0, 1, 4 (частково), 5. Етапи 2 і 3 — див. «Що не зроблено і чому».

## Що змінилося для користувача

- `ENGINE=local` у `settings.txt` — розпізнавання йде на цьому ПК, без інтернету.
- Хмара (`openai/whisper-large-v3-turbo` через OpenRouter) лишилася резервом і
  вмикається сама у трьох випадках: модель ще вантажиться (перші ~3–8 с після
  старту), модель впала, або натиснуто `Ctrl+Alt+L` (примусова мова — це і є
  шлях для німецької).
- Ключ API тепер необов'язковий: без нього програма працює, лише без резерву.
- Двічі програму запустити не можна — другий екземпляр одразу виходить.
- При кожному вимкненні диктування в `dictate.log` пишеться зведення сесії:
  скільки фраз прийнято/відкинуто, медіана затримки, рівень голосу.

| RAM | 64 ГБ |
| GPU | **AMD Radeon RX 560 4 ГБ — CUDA немає**, працюємо лише на CPU |
| Python | 3.11 у `venv\` |
| Мікрофон | USBMIC1 «Микрофон Настольный», 16 кГц моно |

Пункт ТЗ про драйвер NVIDIA і очікування «з GPU 0.2–0.4 с» не застосовні.
Виявилося — і не потрібні.

## Етап 1 — заміри

Модель: `istupakov/parakeet-tdt-0.6b-v3-onnx`, INT8, через `onnx-asr` + `onnxruntime`.
Тестовий набір: 40 останніх реальних фраз з `phrases\` (uk 24, ru 9, en 4, de 3;
1.3–11 с, разом 145 с), ті самі, на яких раніше мірялася хмара.

### Затримка від кінця фрази до тексту

| Потоків | Медіана | p95 | Найгірша (11 с мови) | RAM |
|---|---|---|---|---|
| 2 | 0.25 с | 0.62 с | 0.71 с | +730 МБ |
| 4 | 0.18 с | 0.52 с | 0.57 с | +730 МБ |
| **8** | **0.16 с** | **0.34 с** | **0.48 с** | **+730 МБ** |
| 14 (як у ТЗ: ядра − 2) | 0.34 с | 0.60 с | 0.78 с | +740 МБ |
| Хмара, для порівняння | ~1.0–1.2 с | 5.3 с | до 22 с | — |

Висновки, яких у ТЗ не було:

1. **14 потоків повільніше за 8.** Коли робота розповзається на E-ядра,
   модель чекає найповільніше з них. Формула «фізичні ядра − 2» на цьому CPU
   дає гірший результат. Обрано 8.
2. **Навіть 2 потоки швидші за хмару в 4 рази.** Навантаження на ПК — не проблема.
3. Ціль ТЗ «не більше 1.5 с» була у 5–9 разів слабшою за реальність.
4. Завантаження моделі при старті: 2–8 с (залежить від кешу диска). Іде у фоні,
   в цей час фрази йдуть у хмару.

### Якість проти хмари (ті самі 40 фраз)

Паритет з перекосами в обидва боки, не погіршення.

Локально краще:
- `Victron Energy` латиницею одразу (хмара: «Виктрон Энерджи»)
- «структурировано по подпапкам» (хмара: «под папками»)
- «формирует задания, которые» (хмара: «задание, которое»)

Хмара краще:
- знак питання в кінці питання («…на цьому тижні?» → локально крапка)
- «проєктів» (локально «проектів»), «неуспішних» (локально «не успішних»)
- «7 батарей» цифрою (локально «Сім батарей»)

Німецька — слабка в обох, у локальній гірша: «Ich verstehe» → «Их верстеч».
Це не проблема моделі, а акценту й даних. Рішення: німецьку диктувати
через `Ctrl+Alt+L` (примусова `de` → хмара).

Whisper-галюцинацій (`*breath*`, «Продолжение следует», «Дякую» на тиші)
у Parakeet немає структурно — модель не вчилася на субтитрах.

## Етап 4 — словник

`replacements.txt` працює на тексті будь-якого рушія. 13.09 додано варіанти,
які реально почулися: `лея/дея/Deia → Deye`, `фронеус → Fronius`,
`пилан тич / пайлонтеч / Pilantetch / PylonTach → Pylontech`.

Не зроблено: `Claude Cowork`-варіанти (не було в записах — додати, як почується)
і LLM-вичитка по клавіші. Останнє свідомо: це знову мережа й затримка.

## Етап 5 — здача

- Автозапуск через `shell:startup` не змінювався, ярлик той самий.
- `dictate.log` на місці, формат рядка фрази тепер `local=0.16s` / `cloud=1.2s`.
- Старий хмарний код не видалено (§5 ТЗ).
- `dictate.py` не переписувався: додано один блок (`# --- local ---`)
  і три гілки в `transcribe()`, `main()`, `stop_dictation()`.

## Що не зроблено і чому

**Етап 3 (потоковий режим, дві моделі, RealtimeSTT) — не робити.**
При 0.16 с після кінця фрази повна затримка «останнє слово → текст»
= пауза VAD 0.45 с + 0.16 с ≈ 0.6 с. Потік виграє щонайбільше 0.15 с,
а коштує: друга модель у пам'яті, ризик затерти набраний руками текст,
залежність від чужої бібліотеки, тиждень роботи. Погана угода.

**Етап 2 (робочий день на пробу)** — за замовником.

```
_localtest\         бенчмарки й тести (bench.py, sweep.py, integ.py), у .gitignore
```

## Як перевірити, що працює локально

У `dictate.log` після фрази має бути `local=0.1x s`, а не `cloud=`.
Вимкнути Wi-Fi і продиктувати — текст має з'явитися.
