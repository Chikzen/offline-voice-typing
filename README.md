# GeminiDictate

Глобальный голосовой ввод для Windows с распознаванием украинской, русской,
английской и немецкой речи. Текст вставляется в **любое** активное поле —
браузер, Word, Excel, Telegram, Odoo.

Создан потому, что встроенный голосовой ввод Windows (Win+H) украинский язык
не поддерживает — русский, польский, болгарский есть, украинского нет.

## Как работает

1. Скрипт слушает микрофон непрерывно, пока диктовка включена.
2. Режет поток на фразы по естественным паузам (VAD с адаптивным порогом шума).
3. Каждая фраза уходит на распознавание, до 3 запросов параллельно.
4. Текст вставляется через буфер обмена **строго в порядке произнесения**.

Текст появляется по ходу речи, фразами, а не в конце диктовки.

## Управление

| Действие | Клавиша |
|---|---|
| Вкл/выкл диктовку | двойное нажатие **Ctrl** |
| То же | **Num Lock**, **Scroll Lock**, **Pause** |
| Переключить язык по кругу (авто → uk → ru → de → en) | **Ctrl+Alt+L** |

Num Lock и Scroll Lock после срабатывания автоматически возвращаются в
прежнее состояние, поэтому цифровой блок и стрелки в Excel не ломаются.

Звуковые сигналы: два восходящих — включено, два нисходящих — выключено,
длинный низкий — ошибка. Состояние также показывает плашка внизу справа.

## Установка

```
python -m venv venv
venv\Scripts\python.exe -m pip install keyboard sounddevice requests pyperclip numpy
```

Ключ OpenRouter кладётся в `api_key.txt` (файл в `.gitignore`, в репозиторий
не попадает). Автозапуск — ярлык на `venv\Scripts\pythonw.exe gemini_dictate.py`
в папке `shell:startup`.

## Настройки

Всё в `settings.txt`, перезапуск после изменения. Ключевые параметры:

- `STT_MODEL` — модель распознавания
- `LANGUAGE` — пусто = автоопределение языка каждой фразы
- `ALLOWED_LANGS` — если модель выдала язык вне списка, фраза переспрашивается
- `SILENCE_TAIL` — пауза, после которой фраза считается законченной
- `MIN_PEAK`, `MIN_VOICED` — защита от галлюцинаций на шуме
- `PROVIDER_ORDER`, `HEDGE_AFTER` — борьба с медленными ответами API

## Замеры (09.09.2026, на реальных записях)

Модели, медиана из 5 запросов:

| Модель | Время | Бренды | Цифры |
|---|---|---|---|
| whisper-large-v3-turbo | 1.34 с | ошибается | «20 кВт» верно |
| gpt-4o-transcribe | 1.21 с | верно | словами |
| chirp-3 | 2.82 с | верно | верно |
| локально на CPU (RX 560, без CUDA) | 8.5 с | верно | верно |

Провайдеры OpenRouter: DeepInfra — медиана 2.26 с, максимум 3.25 с;
Groq — медиана 4.70 с, максимум 81.8 с. Отсюда `PROVIDER_ORDER=DeepInfra,Groq`
и дублирующий запрос к другому провайдеру при задержке.

## Решённые проблемы

- **Выдуманный текст.** Чат-модель (Gemini) дописывала целые абзацы, которых
  не было в аудио. Лечится не промптом, а сменой на специализированную модель
  распознавания — она не умеет генерировать свободный текст.
- **«Дякую» на пустом месте.** Модели семейства Whisper на тишине выдают самую
  частую фразу из обучающих данных. Лечится порогом громкости, минимумом
  озвученного времени и фильтром стоковых фраз.
- **Русская речь превращалась в украинскую.** Был жёстко задан `LANGUAGE=uk`.
- **Задержки 12–22 секунды.** Холодный старт провайдера, не модель.
